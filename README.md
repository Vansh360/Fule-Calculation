# ⛽ FuelRoute – Journey Fuel Cost Calculator

FuelRoute is a simple web-based calculator that helps users estimate the **fuel required and total cost of a journey** based on distance, fuel price, and vehicle efficiency. It provides quick calculations, fuel tank visualization, and helpful trip advice to help users plan their journeys more efficiently.


## 🚀 Features

* Vehicle selection with predefined fuel efficiency
* Custom vehicle fuel efficiency input
* Calculate fuel required for a trip
* Estimate total trip fuel cost
* Show extra fuel required before starting the journey
* Fuel tank level gauge visualization
* Smart travel advice based on trip conditions
* Clean, responsive, and user-friendly UI

---

## 🧮 Calculation Logic

Fuel Required = Distance / Vehicle Efficiency

Trip Cost = Fuel Required × Fuel Price

Extra Fuel Needed = Fuel Required − Current Fuel

Tank Level (%) = (Current Fuel / Tank Capacity) × 100
